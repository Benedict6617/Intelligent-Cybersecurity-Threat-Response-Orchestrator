## Short description (GitHub "About" field, ~1 line)
A self-hostable SOAR platform for small security teams: MITRE ATT&CK-based
threat correlation, automated containment playbooks, ITSM ticketing, and
SOC 2/ISO 27001 compliance reporting.

## Longer description (for a pinned repo, portfolio site, or LinkedIn post)
Built a SOAR (Security Orchestration, Automation and Response) platform
designed for small businesses that can't justify enterprise SOAR licensing
but still face real incident-response demands. It ingests telemetry from
SIEM, EDR, firewall, and cloud sources, correlates related events into
incidents using the MITRE ATT&CK framework with an explainable confidence
score, suppresses false positives, runs automated containment playbooks
(with human-approval gates on destructive actions), coordinates ITSM
ticket creation, manages a configurable incident escalation matrix with
SLA tracking, reconstructs forensic timelines, and generates SOC 2 / ISO
27001 audit evidence — all as a single self-hostable FastAPI service with
no proprietary automation DSL or vendor lock-in.

Stack: Python, FastAPI, SQLAlchemy, scikit-learn (IsolationForest anomaly
detection), YAML-defined playbooks, Docker.
